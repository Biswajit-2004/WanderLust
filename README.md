# Wanderlust – Airbnb-Style Property Rental Platform

Wanderlust is a full-stack property rental web application inspired by Airbnb, developed to provide users with a platform where they can explore, create, manage, and book property listings. The application allows property owners to publish their properties with detailed information, while guests can browse available accommodations, explore different categories, and book their preferred stays.

The project follows the **Model-View-Controller (MVC) architecture**, maintaining a structured and organized codebase with a clear separation of concerns.

### Key Features

- **User Authentication:** Implemented user registration and login functionality with secure authentication and cookie-based session management.
- **Property Management:** Property owners can create, view, edit, and delete their listings.
- **Booking System:** Users can explore properties and book accommodations through the application.
- **Search and Filters:** Added search functionality and category-based filters to help users discover relevant properties.
- **Listing Details:** Dedicated property detail pages displaying essential information, images, pricing, and location.
- **Authorization:** Implemented access control to ensure that only authorized users can modify or delete their own listings.
- **Responsive UI:** Designed a responsive user interface that works across desktop and mobile devices.
- **Database Integration:** Used MongoDB and Mongoose to design schemas and manage application data.
- **RESTful APIs:** Developed backend routes and APIs to handle listings, user authentication, and booking-related operations.
- **Form Validation and Error Handling:** Implemented input validation and structured error handling to improve application reliability.

### Technology Stack

- **Frontend:** HTML, CSS, JavaScript, EJS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** Passport.js, Express Sessions, Cookies
- **Architecture:** MVC Pattern, RESTful APIs
- **Tools:** Git, GitHub, VS Code

### Development Approach

This project was developed independently, covering the complete development lifecycle, from planning and database schema design to backend development, frontend integration, authentication, authorization, and application functionality.

Building Wanderlust helped me strengthen my understanding of full-stack web development, REST API design, database relationships, server-side rendering, authentication workflows, and real-world application architecture.

**Wanderlust represents my practical implementation of full-stack development concepts through an end-to-end property rental application.**
